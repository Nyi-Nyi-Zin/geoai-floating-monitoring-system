# Maubin Terrain-Screening Visual Verification

**Verification date:** 2026-08-18

The rendered Maubin Flood Risk map was visually inspected after restoring the static terrain-screening style. The terrain layer visibly contains all four configured screening colors at the same time: **blue** for lower terrain screening, **yellow** for moderate terrain screening, **orange** for high terrain screening, and **red** for very high terrain screening.

The left-side legend presents the same four bands and states: “Static terrain screening, not a real-time probability or warning.” The dashboard’s hindcast panel and status bar continue to display the separate **Monitoring only** boundary. This confirms that the Flood Risk layer is a four-band static terrain-screening presentation and not a binary historical-hindcast probability display.
